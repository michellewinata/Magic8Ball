🎱 Magic 8 Ball
Magic 8 Ball is a simple iOS app built with Swift and UIKit. The app simulates a Magic 8 Ball by displaying a random answer every time the user presses the Ask button.

✨ Features
- Displays a Magic 8 Ball image
- Generates a random answer when the user taps Ask
